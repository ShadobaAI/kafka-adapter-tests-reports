# Repository Agent Instructions

## Workspace Instructions

Read the required [workspace instructions](../../AGENTS.md) before working in this repository. The fixed `KAFKA_PROJECTS_ROOT` layout is required. If the shared file is missing, report a workspace-layout error and stop. The repository-specific rules below supplement and override the shared rules when they conflict.

## Repository Scope

This repository publishes generated Allure UI, Allure Unit, and Sonar reports through GitHub Pages. Start with [README.md](README.md). Report directories are generated by the publishing workflow and are not hand-maintained source.

## Repository-Specific Rules

- Never manually edit `latest/`, `<run_id>-<run_attempt>/`, Allure output, Sonar output, or other generated report content.
- Generated directories can be overwritten or deleted by the next publishing workflow.
- Edit only `README.md`, GitHub Pages/Actions configuration, or service files when the task explicitly concerns report publication.
- Validate configuration and links without modifying generated content.
- Do not delete old runs unless the user explicitly requests the exact destructive scope.
